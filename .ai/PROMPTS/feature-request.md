## 4. Критерии приёмки

Формат: действие → ожидаемый результат, который можно проверить.

- [ ] `[Открываю X → вижу Y]`
- [ ] `[Отправляю неверный Z → получаю понятную ошибку, данные не пишутся]`
- [ ] `[Повторяю действие дважды → создаётся одна запись, а не две]`
- [ ] `[Существующие сценарии A и B работают как раньше]`
- [ ] `[Линт / типы / тесты / сборка проходят]`
- [ ] `[Новые ошибки видно в логах без персональных данных и секретов]`
