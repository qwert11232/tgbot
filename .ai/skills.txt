# 🛠️ skills.txt — список внешних скиллов (GitHub)

> Файл-каталог: откуда агенту брать готовые методики под этот проект.
> Формат — один идентификатор на строку, с префиксом `GITHUB_ID:`.
> Строки, начинающиеся с `#`, — комментарии и не разворачиваются.
>
> **Как агент разворачивает список:**
> 1. Собрать URL: `https://github.com/<OWNER>/<REPO>.git`.
> 2. Склонировать **только для чтения** в `.ai/skills/<OWNER>_<REPO>/`
>    (папка в `.gitignore` — в репозиторий не попадает).
> 3. Прочитать `SKILL.md` / `skill.md` / `README.md` каждого репозитория.
> 4. Применять методики к коду проекта; не копировать чужие файлы целиком без адаптации.
>
> Пример создания URL:
> `GITHUB_ID: owasp/CheatSheetSeries` → `https://github.com/owasp/CheatSheetSeries.git`
>
> Пока список пуст — каркас работает без внешних скиллов. Добавляйте по мере надобности,
> по одной-две ссылки под конкретную задачу, а не «всё, что нашли».
